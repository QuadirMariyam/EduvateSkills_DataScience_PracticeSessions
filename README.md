Eduvateskills Data Science materials <br>

To run any python application <bR>
- activate the virtual environment using the relative path of Venv >> Scripts >> Activate >> ps1 (a green colored interpreter will be updated on the left)
- run the command $python app.py
- a numbered link will be generated, follow the link to see the application

To run a python application using virtual environment for the first time <br>
- Navigate to Your Project Directory, using the following command $cd <your project folder path>
- create virtual environment by changing the python interpreter or running the command $python -m venv <name of your choice> 
- activate and run the application using the steps above
- deactivate
